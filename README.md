# Simpul monorepo

| Folder | What | Source repo |
| --- | --- | --- |
| [`backend/`](backend) | API server | [simpul-backend](https://github.com/meQlause/simpul-backend) |
| [`frontend/`](frontend) | Web app | [simpul-frontend](https://github.com/meQlause/simpul-frontend) |
| [`frontend-landing-page/`](frontend-landing-page) | Landing page | [simpul-frontend-landing-page](https://github.com/meQlause/simpul-frontend-landing-page) |

Each folder is a standalone npm package; see its README to install, run and test it.

Clone with the submodules: `git clone --recurse-submodules https://github.com/meQlause/simpul-monorepo`
